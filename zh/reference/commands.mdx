所有命令都在目标仓库根目录运行。本文省略重复的 `npx @caesarlo/sdlc-harness` 前缀；未安装 CLI 时请加上该前缀。

```bash
npx @caesarlo/sdlc-harness --help
```

每个子命令自身也接受 `-h`/`--help`——出现在参数任意位置都生效，不必是第一个参数——命中后会打印该命令自己的用法说明，而不是真的执行它。

```bash
npx @caesarlo/sdlc-harness feature --help
npx @caesarlo/sdlc-harness milestone archive -h
```

## 仓库与审核

| 命令 | 作用 | 参数说明 |
| --- | --- | --- |
| `init [--force]` | 生成完整协议；遇到已有文件默认停止并列出冲突 | [查看 `init` 参数 →](/zh/reference/command-repository#init) |
| `adopt` | 只插入缺失文件；已有 `AGENTS.md` 时生成 sidecar | [查看 `adopt` 说明 →](/zh/reference/command-repository#adopt) |
| `validate` | 运行全部治理审核；失败时返回非零 | [查看 `validate` 说明 →](/zh/reference/command-repository#validate) |
| `status` | 输出功能、审批、追溯和下一步的 JSON 摘要 | [查看 `status` 说明 →](/zh/reference/command-repository#status) |
| `traceability` | 输出完整追溯矩阵；存在实际缺口时返回非零 | [查看 `traceability` 说明 →](/zh/reference/command-repository#traceability) |

## 功能生命周期

| 命令 | 状态变化 | 参数说明 |
| --- | --- | --- |
| `feature start <feature-id>` | 检查 ready、依赖和 WIP，认领并进入 `in_progress` | [查看 `start` 参数 →](/zh/reference/command-feature#start) |

## Claim 与租约

| 命令 | 作用 | 参数说明 |
| --- | --- | --- |
| `claim <feature-id>` | 认领指定功能 | [查看 `claim` 参数 →](/zh/reference/command-claim#claim) |
| `claim --next` | 按依赖、priority 和列表顺序选择 ready 功能 | [查看 `--next` 参数 →](/zh/reference/command-claim#next) |
| `claim renew <feature-id>` | 从当前时间续租已有 claim | [查看 `renew` 参数 →](/zh/reference/command-claim#renew) |
| `claim <feature-id> --takeover-expired` | 接管已过期 claim | [查看接管参数 →](/zh/reference/command-claim#takeover-expired) |
| `claim <feature-id> --push` | 认领、提交并推送；远端冲突时尝试下一个功能 | [查看 `--push` 参数 →](/zh/reference/command-claim#push) |
| `release <feature-id>` | 释放 claim，并把 `in_progress` 恢复为 `not_started` | [查看 `release` 参数 →](/zh/reference/command-claim#release) |

<Note>
  Solo 模式通常无需手动 claim；`verify` 会按需为 `defaultOwner` 临时认领并释放。Team 模式必须事先持有有效 claim。
</Note>

## 通用默认值

| 参数 | 默认值 |
| --- | --- |
| claim 和生命周期命令的 `--owner` | `harness.config.json.defaultOwner` |
| `provider github check` 与 `evidence import` 的 GitHub 仓库 `--owner` | 从 `origin` 推断；无法推断时必须提供 |
| `--ttl` | 120 分钟 |
| `--remote` | `origin` |
| `--branch` | `main` |
| `--base` | `main` |

`--actor` 的默认值因命令而异，具体以对应参数页为准。

<Warning>
  `init --force` 和 `workspace ... --force` 可能覆盖文件或丢弃未提交、未推送的工作。使用前先阅读对应参数页和命令输出。
</Warning>
