---
title: "Workspace commands"
description: "Create, inspect, remove, and prune Git worktree workspaces."
icon: "code-branch"
---

Workspaces use Git worktrees to create an isolated directory and a `feature/<feature-id>` branch for a feature.

## `workspace create` {#create}

```bash
npx @caesarlo/sdlc-harness workspace create <feature-id> [--base <branch>]
```

| Argument | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `<feature-id>` | string | Yes | — | Feature ID that has an active claim and no existing workspace. |
| `--base` | Git ref string | No | `main` | Base branch or ref for the new feature branch. Git must be able to resolve it. |

On success, the command creates `.worktrees/<feature-id>` and the `feature/<feature-id>` branch, then writes workspace metadata to `feature_list.json`.

## `workspace status` {#status}

```bash
npx @caesarlo/sdlc-harness workspace status
```

This command has no arguments. It outputs JSON containing each registered workspace's path, branch, base commit, whether the claim is active, and whether the directory still exists. It does not modify the repository.

## `workspace remove` {#remove}

```bash
npx @caesarlo/sdlc-harness workspace remove <feature-id> [--force]
```

| Argument | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `<feature-id>` | string | Yes | — | Feature ID with a registered workspace. |
| `--force` | boolean | No | `false` | Remove even when uncommitted changes or unpushed commits exist. |

By default, the command protects uncommitted and unpushed work. On success, it removes the worktree, feature branch, and workspace metadata.

## `workspace prune` {#prune}

```bash
npx @caesarlo/sdlc-harness workspace prune [--force]
```

The command considers only workspaces whose claims have been released or expired. It always skips workspaces with active claims. By default, it also skips directories with uncommitted or unpushed work. `--force` removes those directories as well.
