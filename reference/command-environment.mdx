## `env` {#env}

List the environment commands configured in `harness.config.json.commands`.

```bash
npx @caesarlo/sdlc-harness env
```

This command has no arguments and does not execute the listed commands.

## `env check` {#env-check}

Run the configured environment checks in sequence.

```bash
npx @caesarlo/sdlc-harness env check
```

This command has no arguments. The fixed execution order is `bootstrap`, `verify`, `e2e`, then `health`. It runs only configured entries and stops after the first failure. It returns `0` if all checks pass or none are configured, and returns nonzero if any command fails.

Here, `commands.verify` is a project-level environment check, not a feature's `sdlc-harness verify <feature-id>`.

## `session close` {#session-close}

Summarize repository health at the end of a session.

```bash
npx @caesarlo/sdlc-harness session close
```

This command has no arguments. It runs `validate` and the environment checks, then summarizes the Git worktree, current commit, feature counts, and next steps. It exits nonzero if any component check fails.

`session close` does not automatically commit, push, release claims, or remove workspaces.
