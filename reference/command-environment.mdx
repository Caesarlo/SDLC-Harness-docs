## `env` {#env}

列出 `harness.config.json.commands` 中已配置的环境命令。

```bash
npx @caesarlo/sdlc-harness env
```

该命令没有参数，也不会执行列出的命令。

## `env check` {#env-check}

依次运行已配置的环境检查。

```bash
npx @caesarlo/sdlc-harness env check
```

该命令没有参数。执行顺序固定为 `bootstrap`、`verify`、`e2e`、`health`，只运行存在的配置项，并在第一次失败后停止。全部通过或没有配置项时返回 `0`；任一命令失败时返回非零。

这里的 `commands.verify` 是项目级环境检查，不是功能的 `sdlc-harness verify <feature-id>`。

## `session close` {#session-close}

汇总会话结束时的仓库健康状态。

```bash
npx @caesarlo/sdlc-harness session close
```

该命令没有参数。它运行 `validate` 和环境检查，然后汇总 Git 工作区、当前 commit、功能计数和下一步。任何组成检查失败时返回非零。

`session close` 不会自动提交、推送、释放 claim 或移除 workspace。
