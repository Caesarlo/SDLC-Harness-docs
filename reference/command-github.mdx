## `provider github check` {#check}

Check whether a GitHub repository has the protections required by SDLC Harness.

```bash
npx @caesarlo/sdlc-harness provider github check \
  [--owner <github-owner>] [--repo <github-repo>] [--branch <branch>]
```

| Argument | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `--owner` | string | Conditionally | Inferred from `origin` | GitHub repository owner. Required when it cannot be inferred. |
| `--repo` | string | Conditionally | Inferred from `origin` | GitHub repository name. Required when it cannot be inferred. |
| `--branch` | string | No | `main` | Branch whose protection rules are checked. |

The `gh` CLI must be installed and authenticated locally. Conclusions in the output mean:

- `PASS`: the configuration meets the requirement.
- `FAIL`: the configuration is confirmed not to meet the requirement, and the command exits nonzero.
- `UNKNOWN`: the token lacks enough permission to confirm the configuration. This is a warning, not a failure.

This command only checks GitHub repository configuration. It does not run feature verification or replace `validate`.
